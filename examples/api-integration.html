API Demo

Interactive API Integration Example - Test and Explore Video Encoding Endpoints

🚀 Quick Start

This interactive demo allows you to test Voltage API endpoints directly from your browser. Configure your API endpoint below and explore various operations like health checks, authentication, job submission, and monitoring.

📌 Before you start: Make sure your Voltage instance is running and accessible. Default local endpoint is http://localhost:4000

🔐 Authentication

Authenticate with the API to receive an access token for protected endpoints. Your token will be saved and used automatically for all subsequent requests.

🔧 API Operations

Health Check

Check if your Voltage instance is running and healthy.

Configuration

View the current Voltage configuration settings.

Submit Encoding Job

Submit a new video encoding job to Voltage. Modify the JSON payload below or use the default example.

List Encoding Jobs

Retrieve the list of encoding jobs from your Voltage instance.

List Instances

View all processing instances and their workers.

Job Notifications

View webhook notifications sent for job status updates.

System Logs

View system logs and activity.

Statistics

View statistics about your Voltage instance performance and usage.

📚 API Reference

Quick reference for available Voltage API endpoints. Click on any operation above to test them interactively.

🔍 Health & Config

GET /status - Service health check

GET /config - Configuration info

🔐 Authentication

POST /auth - Get access token

🎬 Jobs

GET /jobs - List jobs

POST /jobs - Create job

POST /jobs/retry - Retry job

DELETE /jobs - Delete jobs

📊 Statistics

GET /stats - Get statistics

DELETE /stats - Delete stats

📝 Logs

GET /logs - Fetch logs

DELETE /logs - Delete logs

⚙️ Instances

GET /instances - List instances

GET /instances/workers - List workers

✨ Voltage Features

🎥 Video Encoding

FFMPEG-based encoding with full customization support. Multiple output formats, codecs, and quality settings.

📦 Multi-Storage

Support for local, S3, FTP, SFTP storage backends. Easy integration with your existing infrastructure.

🤖 AI-Powered

Built-in Whisper transcription and NSFW detection for intelligent content processing.

📊 Real-time Monitoring

Track job progress, view statistics, and monitor system health through the web interface.

🔄 Job Queue

Priority-based job queue with retry mechanisms and webhook notifications.

⚡ Scalable

Multi-instance architecture for horizontal scaling and parallel processing.
